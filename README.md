# Library Management System Database

## Description

This project is a complete relational database management system designed for managing a library’s operations. It is implemented entirely in MySQL and supports:

- Managing books, authors, publishers, categories, and library members
- Tracking book loans including loan, due, and return dates
- Many-to-many relationships between books and authors
- Enforcing data integrity with primary keys, foreign keys, unique constraints, and NOT NULL fields

The database schema provides a robust foundation for building library software or integrating with a library management application.
